# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

`lemuel-tech/lemuel-tech` is a GitHub **profile README** repository — the special
repo (named identically to the GitHub username) whose `README.md` is rendered
on the owner's GitHub profile page. It is not an application or library.

The entire repository consists of a single file: `README.md`.

## Working in this repository

- There is no build, lint, or test tooling — none is needed. Do not add
  package managers, CI configs, or scaffolding unless the user explicitly
  asks for the repo to become something else.
- Changes here are edits to profile-facing prose/markdown (bio, interests,
  contact info, badges, stats widgets, etc.), not code changes.
- Keep edits scoped to what renders on the GitHub profile. Preview changes
  by checking the rendered Markdown, since that's the only "output" this
  repo has.
